# Model Card

## Общая информация

**Название модели:** roberta-spam

**Источник:** https://huggingface.co/mshenoda/roberta-spam

**Автор / организация:** mshenoda

**Задача модели:** Бинарная классификация текста (определение спама).

**Язык:** Английский.

## Использование в проекте

Модель используется как основной классификатор в сервисе проверки входящих писем. Когда пользователь отправляет письмо через `POST /emails/check`, текст передаётся в модель. Модель возвращает метку принадлежности к спаму и уверенность, которые сохраняются в системе и отображаются пользователю. Результат также используется для автоматической пометки письма в почтовом ящике.

## Входные данные

Текст письма.

## Выходные данные

Бинарная метка: `0` (не спам) или `1` (спам), уверенность модели (от 0 до 1).

## Метрики качества

Авторами модели указаны метрики Accuracy = 99.06%, Precision = 99.71%, Recall = 99.34% и матрица ошибок для тестовой выборки.

## Ограничения

Явные ограничения модели не указаны авторами модели в карточке на Hugging Face. На основе анализа состава датасета и архитектуры модели можно выделить следующие потенциальные ограничения для нашего проекта:

1. Языковое ограничение. Модель обучена на англоязычных датасетах. Качество классификации русскоязычных писем не гарантируется и требует отдельной проверки.
2. Только текстовый анализ. Модель не анализирует вложения, ссылки и скрытые заголовки. Если спам замаскирован в картинке или URL, модель его пропустит.
3. Возможны ложные срабатывания (легитимные письма помечаются как спам), особенно на новых видах спама.

## Не рекомендуется использовать

Не указано авторами модели.
