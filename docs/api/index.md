# API

API предоставляет доступ к функциям ИИ-сервиса по проверке входящих писем на спам.

## Основные операции

- `POST /emails/check` — отправить письмо на проверку и получить результат классификации;
- `GET /emails/{emailId}/result` — получить сохранённый результат проверки конкретного письма;
- `GET /models` — получить информацию о текущей используемой ML-модели.

## Спецификация

Полное описание API находится в файле [`openapi.yaml`](openapi.yaml).
