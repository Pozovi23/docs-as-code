# Система определения спама

Сервис автоматически анализирует входящие письма, определяет, является ли письмо спамом, и при необходимости помечает его как спам.

Основные пользователи:
- получатель письма (владелец почтового ящика);

Основные функции:
- анализ входящего письма;
- классификация письма (спам / не спам);
- пометка письма как спама.
